* Adding a new wireguard connection
1. Import a new provider =.conf= file into NetworkManager.
2. Change settings, if needed.
3. Encrypt the resulting =.nmconnection= file into =secrets/wireguard/=.
   #+begin_src bash
   sudo cat /etc/NetworkManager/system-connections/new.nmconnection |
   sops encrypt \
       --filename-override secrets/wireguard/vpn-X.nmconnection.enc \
       --input-type binary \
       --output-type json \
       > secrets/wireguard/vpn-X.nmconnection.enc
   #+end_src
4. Add the encrypted file to Git and rebuild NixOS.
5. Retire the original unencrypted profile to avoid duplicates.
